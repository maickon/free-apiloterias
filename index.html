Atualização Automática

Um CRON job coleta os resultados da Caixa e faz commit nos JSONs automaticamente.

Servido pelo GitHub

Os arquivos JSON ficam no repositório e são servidos pelo raw.githubusercontent.com.

Sem Chave de API

Basta fazer um GET para a URL. Sem cadastro, sem autenticação, sem rate limit proprietário.
